Процесс:

0. пользователь регистрируется либо как бизнес, либо как студент.
1. создаются команды для студентов
2. Бизнес создает новую карточку. Может использовать либо голосового ассистента, либо текстовый чат, либо заполнить самостоятельно.
3. В первых 2-х случаях ИИ раскладывает всю информацию на отдельные поля:
   набор стандартных полей для всех проектов: Название, контекст, потребность, пользователи,
   данные, ограничения, ожидаемый результат, критерии
   успеха, контакт и формат взаимодействия
   + динамический набор полей в зависимости от конкретного проекта: .....

4. Задается от 3-х уточ. вопросов. Во время разговора на каждом шагу ИИ дает предварительную оценку полноты проекта, и продолжает задавать вопросы, пока не пересечет минимальный порог, чтобы заполнить только базовые данные для создания карточки.

5. После создания карточки ей выдается оценка по фиксированным критериям и карточка публикуется, ИИ автоматически назначает стомость задачи в баллах, которые при выполнении начисляются каждому студенту команды и в общий командный аккаунт

6. студенты могут откликаться только от команд. капитан формирует отклик на карточку, с заполненными идеями

7. при подаче откликов с идеями бизнес может посмотреть состав команды. у каждого участника выделяются отдельно теги, которые соответствуют тегам задачи

8. бизнес выбирает все интересующие команды, либо отклоняет

9. команда выполняет задание, по завершению задачи начисляются баллы. бизнесу предлагается оставить отзыв

====

1. Студенты регистрируются и добавляют свои навыки
2. Студент может создать команду (с названием и лого) и пригласить туда других
3. Одинокие студенты все равно должны создать команду из одного человека

раздельные рейтинги для студентов и команд

Таблицы:

1. Пользователи (роли: суперадмин (SUPERADMIN), владелец бизнеса (BUSINESS), студент (USER))

2. Карточки пользователей (теги, портфолио, ссылки на соцсети, личный сайт, мб личные тема для личной страницы?)

3. Команды (ид капитана, название, лого)

4. Бизнесы (ид владельца)

5. Карточки

6. Отклики

7. ответы на отклики

7. История бесед с ботом

8. Сообщения м/у пользователями

9. Отзывы

10. история баллов команд+пользователей+бизнесов

11. Теги
